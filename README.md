## How it is built

**Rendering**

- **The corridor** (`src/three/createGateScene.ts`). A three.js scene behind the whole page. Scroll moves the camera through one gate per chapter; the pieces between gates follow one round of play: the deal, the roll, the thinking, the win, the machinery. Pieces drift from the cursor and take a kick from a click or tap. Desktop gets a bloom pass and real glass refraction; phones skip both.
- **The particle portrait** (`src/three/createPortraitParticles.ts`). Every lit pixel of the photo becomes a point with a depth taken from its brightness. One draw call; all the motion is in the vertex shader.
- **The nebula** (`src/components/ui/turbulent-flow.tsx`). A raymarched volumetric shader in raw WebGL, about 40 lines of GL plumbing and no library.
- three.js is a separate chunk that loads after first paint, so it never competes with the first screen. The chess pieces are CC0 geometry from Poly Haven, stripped to positions and normals and dressed in the site's own materials (see [`public/models/CREDITS.md`](public/models/CREDITS.md)). Cards, dice, coins and the trophy are built in code.

**Motion**

- Native scroll-driven CSS (`view-timeline`) runs the pinned gallery, the studio iris and the career spine. Browsers without it get a small scroll listener or a static layout.
- The pinned gallery is a sticky viewport, so it cannot go stale when something above it changes height.
- There is no animation library on the page.

**Behaviour that protects the experience**

- A frame-time watchdog halves the 3D resolution if frames run long, then stops the scene and leaves the CSS backdrop.
- Machines without a GPU never start the corridor.
- With reduced motion, the loader, the pinning, the particles and the scroll effects are off and everything is visible from the start.
- On narrow screens the 3D layer dims while you read and brightens while you scroll.

**Accessibility**

- axe reports no violations on the desktop and phone layouts (WCAG 2.2 AA plus best practice).
- The section menu is a native `<dialog>`. The stack is a real tab list with arrow keys. The phone gallery is a carousel with named buttons, markers and a polite status announcement.
- Text links have 44px hit areas on touch.

## Stack

| Layer | Choice |
|---|---|
| UI | React 19, TypeScript in strict mode, CSS Modules, no UI or CSS framework |
| 3D | three.js (lazy chunk), raw WebGL for the background shader |
| Motion | Scroll-driven CSS animations, CSS transitions, `requestAnimationFrame` hooks |
| Build | Vite 6 |
| Deploy | GitHub Actions to GitHub Pages on every push to `main` |

## Run it locally

Node 22.x. No environment variables.

```bash
git clone https://github.com/EdgarHovsepyan/EdgarHovsepyan.github.io.git
```

```bash
cd EdgarHovsepyan.github.io && npm install
```

```bash
npm run dev
```

| Script | What it does |
|---|---|
| `npm run dev` | Dev server with hot reload |
| `npm run build` | Type-check, then bundle to `dist/` |
| `npm run preview` | Serve the production build |
| `npm run typecheck` | Type-check only |

Add `?gl=force` to the URL to run the 3D scene on a machine without a GPU.

## Generated files

| What | Source | Command |
|---|---|---|
| ATS CV (`public/cv/*_ATS.pdf`, `.docx`) and `CV-2026.md` | `tools/build_cv.py` | `python3 tools/build_cv.py` |
| Designed and Light CV, one page each | `tools/cv-print-premium.html`, `tools/cv-print-branded.html` | `node tools/print_cv.cjs` |
| Social preview, README banner and hero screenshot | `tools/og-image.html`, `tools/banner.html` | `node tools/render_og.cjs` |
| `CONTENT.md`, the text mirror of `src/data` | `src/data/*.ts` | `node tools/sync_content.mjs` |
| The showreel (`public/assets/showreel.mp4`) | `reel/src/Reel.tsx`, a Remotion project with its own `package.json` | `cd reel && npm install && npm run render` |

The two `.cjs` scripts need the built site served on port 4173 (`npm run build`, then `npx vite preview`), so the templates can load the site fonts. [`LINKEDIN.md`](LINKEDIN.md) is a hand-kept draft of the profile text.
